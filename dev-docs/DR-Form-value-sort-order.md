#### Issue 
We want values that appear in dropdowns on forms to be alphabetical
#### Problem Statement
On Google Tables form, the values currently in our dropdown table are not showing up alphabetically, nor are they ordered by how they appear in the CoP database table.
#### Potential Solution
Solution 1. Figure out how to get Google Tables forms to be sorted
Solution 2. use something else (possibly Google Forms)
#### Feasibility Determination
This turned out to not be possible in Google Tables so we went with solution 2, and we are making a Google Form that inputs to will end up writing to the table.  This allows not just sorting of values but also regex on fields to insure inputs are formatted correctly by the user.
